# emy.dev 🌿

A small corner of the web for my work as a software engineer.

**Visual direction:** Dark Editorial × Minimal Jungle — deep forest greens, warm off-white typography, and restrained coral accents.

## Tech stack

- [Astro](https://astro.build/) — static site generation
- TypeScript
- Plain CSS
- GitHub Pages + GitHub Actions

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:4321`.

## Deploy

The workflow in `.github/workflows/deploy.yml` deploys every push to `main`.

In GitHub, open **Settings → Pages → Build and deployment → Source** and select **GitHub Actions**. The site will then be available at https://emyrtille.github.io after a successful workflow run.
